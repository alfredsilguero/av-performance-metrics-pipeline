# Autonomous Vehicle Performance Metrics Pipeline

This repository contains a Python-based pipeline for simulating, processing, and analyzing autonomous vehicle performance metrics. The key metrics include lane deviation, braking time, and stop time — which are critical for evaluating autonomous driving systems.

## Project Overview

- **Data Simulation**: Generate simulated AV sensor data such as lane deviation, braking time, and stop time to assess autonomous vehicle performance.
- **Metrics Calculation**: The pipeline calculates key performance metrics including average lane deviation, braking time, and stop time.
- **Visualization**: The project visualizes performance metrics using histograms to help identify patterns and analyze AV system behavior.

## Technologies Used

- **Python** (Pandas, NumPy, Matplotlib)
- Data simulation and processing
- Data visualization
